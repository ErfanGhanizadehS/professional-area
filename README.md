Program Topic: Geometric Calculations Management Program
Given Data: User's menu selection, dimensions of geometric shapes
Relationship: Calculation of perimeter and area + management of results list
Solution Method:

The program displays a main menu with various options.

Storage Lists:

Circle Perimeter List

Circle Area List

Rectangle Perimeter List

Rectangle Area List

Main Menu:

Calculate Circle Perimeter

Calculate Circle Area

Calculate Rectangle Perimeter

Calculate Rectangle Area

Display All Lists

Delete an Item from the Lists

Exit the Program

Details of Each Option:

Option 1: The user enters the radius, the circle's perimeter is calculated and added to the list.

Option 2: The user enters the radius, the circle's area is calculated and added to the list.

Option 3: The user enters the length and width, the rectangle's perimeter is calculated and added to the list.

Option 4: The user enters the length and width, the rectangle's area is calculated and added to the list.

Option 5: All lists are displayed with their stored values.

Option 6: A submenu for deleting an item is displayed.

The user selects which list to delete from.

If the list is empty, an error message is displayed.

If the list is not empty, the selected item is deleted.

Option 7: The program ends with a farewell message.

The program runs in an infinite loop until the user selects Option 7.
